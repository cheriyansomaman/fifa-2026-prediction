# Point rules

As part of a prediction game for the FIFA 2026 world cup, points will be awarded based on the accuracy of the predictions for both the group stage and knockout stage matches. The following rules will apply for awarding points:

## Group stage


In a group stage match, there are three possible outcomes: a win for either team or a draw.
Points will be awarded based on the following criteria:

- Exact match - 5 points
    - Example: match prediction is 3-1, match result is 3-1
- Predicted team wins and gold difference is same as match result - 4 points
    - Example: match prediction is 5-2, match result is 3-0
- Predicted team wins and goal difference is not same as match result - 3 points
    - Example: match prediction is 5-2, match result is 4-1
- Predicted team loses - 0 points
    - Example: match prediction is 1-2, match result is 3-0
- Predicted draw and match result is draw with exact goal score - 5 points
    - Example: match prediction is 1-1, match result is 1-1
- Predicted draw and match result is draw with different goal score - 3 points
    - Example: match prediction is 1-1, match result is 0-0
- Predicted draw and match result is not draw - 0 points
    - Example: match prediction is 1-1, match result is 2-1
- Predicted team wins and match result is draw - 1 point
    - Example: match prediction is 2-1, match result is 1-1
- Predicted team loses and match result is draw - 1 point
    - Example: match prediction is 1-2, match result is 1-1

## Knockout stage

In a knockout stage match, there are two possible outcomes: a win for either team or a draw (which may lead to extra time and penalties).
Note: Penality shootout is only happens when the result is draw after 90 minutes and extra time. If the match result is not draw, then the penalty shootout result will not be considered for awarding points.
Points will be awarded based on the following criteria:

- Exact match - 5 points
    - Example: match prediction is 3-1, match result is 3-1
- Predicted team wins and goal difference is same as match result - 4 points
    - Example: match prediction is 5-2, match result is 3-0
- Predicted team wins and goal difference is not same as match result - 3 points
    - Example: match prediction is 5-2, match result is 4-1
- Predicted team loses - 0 points
    - Example: match prediction is 1-2, match result is 3-0
- Predicted draw and match result is draw with exact goal score - 4 points + 1 point for predicting penalties shootout correctly
    - Example: match prediction is 1-1, penalty 4-5, match result is 1-1 4-5
- Predicted draw and match result is draw with different goal score - 3 points + 1 point for predicting penalties shootout correctly
    - Example: match prediction is 1-1, penalty 4-5, match result is 0-0 4-5
- Predicted draw and match result is not draw - 0 points
    - Example: match prediction is 1-1, match result is 2-1
- Predicted team wins and match result is draw - 1 point
    - Example: match prediction is 2-1, match result is 1-1
- Predicted team loses and match result is draw - 1 point
    - Example: match prediction is 1-2, match result is 1-1
- Predicted team wins by penalty shootout - 4 points
    - Example: match prediction is 1-2, match result is 1-1 4-5
